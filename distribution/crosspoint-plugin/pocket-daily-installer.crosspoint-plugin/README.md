Pocket Daily

Pocket Daily is an independent reading firmware for Xteink X3 and X4 readers,
built on CrossPoint. It is not made or endorsed by the CrossPoint project.
It pairs with the Pocket Daily companion app for book transfer and reading
position sync. Use it only on an X3 or X4.

This plugin only downloads the firmware file. Nothing is installed until you
confirm it on the reader.

Install

1. Connect the reader to Wi-Fi.
2. Open Home > Plugins > Pocket Daily and choose a release.
3. Choose Fetch. The file is saved as /pocket-daily.bin on the SD card.
4. Open Settings > System > SD Card Firmware Update, choose pocket-daily.bin
   and confirm. The reader checks the file again before installing it.
5. The reader restarts into Pocket Daily. Your books stay on the SD card;
   books are laid out again the first time you open them.

If the list is empty, no Pocket Daily release is published yet.

If the download stops, nothing is installed. Try again, or copy
pocket-daily.bin to the top folder of the SD card with a computer.

Going back

Download the CrossPoint firmware.bin you want from the CrossPoint releases
page, copy it to the top folder of the SD card, and install it the same way
from Settings > System > SD Card Firmware Update.

Already running Pocket Daily? Use its own update check instead of this plugin.
